# Plan: Add loading.tsx for Each Route

## Context
The project currently has a single root `loading.tsx` at `src/app/loading.tsx` that just shows `<p>Loading...</p>`. The goal is to add route-specific `loading.tsx` files with skeleton UI tailored to each route's purpose. The root `loading.tsx` stays as a catch-all fallback. The project uses Tailwind CSS + shadcn/ui.

## Design Approach
- Use **skeleton** patterns (animated gray blocks) matching Tailwind's `animate-pulse`
- Each loading.tsx is a **Server Component** (no `"use client"` needed for simple skeletons)
- Group similar pages to share skeleton patterns:
  - **Auth pages**: centered form skeleton
  - **Dashboard pages**: stats cards + chart skeleton
  - **Management pages**: table skeleton (search bar + rows)
  - **Card grid pages**: repeating card skeletons
  - **Form pages**: labeled input field skeletons
- Keep components lightweight — no interactivity needed
