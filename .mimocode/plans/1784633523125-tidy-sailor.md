# Fix: DashboardLayout কেন render হচ্ছে না

## Problem

`src/app/(dashboardLayout)/` ফোল্ডারে **কোনো `layout.tsx` নেই**। শুধুমাত্র route group হিসেবে কাজ করছে, কোনো UI wrapper দেয় না।

## Current Structure

```
src/app/
├── layout.tsx                          ← RootLayout (সবকিছু wrap করে)
│
├── (commonLayout)/
│   ├── layout.tsx                      ← CommonLayout ✅ আছে
│   ├── page.tsx                        ← "/" home page
│   └── ...public pages
│
└── (dashboardLayout)/
    ├── ❌ layout.tsx নেই!              ← এটাই সমস্যা
    ├── (commonProtectedLayout)/
    │   └── layout.tsx
    ├── (patientRouteGroup)/
    │   └── ...patient layouts
    ├── admin/dashboard/
    │   └── layout.tsx
    └── doctor/dashboard/
        └── layout.tsx
```

## Root Cause

Next.js App Router-এ `(dashboardLayout)/` একটি **route group** — এটি URL-এ affect করে না, শুধু ফাইল অর্গানাইজেশনের জন্য। কিন্তু এই ফোল্ডারে `layout.tsx` না থাকলে, ভেতরের সব route-এ কোনো shared layout apply হয় না।

- `"/"` → `RootLayout → CommonLayout → page.tsx`
- `"/admin/dashboard"` → `RootLayout → AdminDashboardLayout → page.tsx` (কোনো intermediate dashboard layout নেই)

## Solution

`src/app/(dashboardLayout)/layout.tsx` তৈরি করুন। এটি সব dashboard route-কে wrap করবে।

### File to create: `src/app/(dashboardLayout)/layout.tsx`

```tsx
import { Fragment } from "react";

export default function DashboardLayout({
  children,
}: Readonly<{
  children: React.ReactNode;
}>) {
  return (
    <Fragment>
      <h1 className="text-blue-500 font-bold text-2xl">Dashboard Layout</h1>
      {children}
    </Fragment>
  );
}
```

## Resulting Layout Nesting

| URL | Layout Chain |
|-----|-------------|
| `/` | RootLayout → CommonLayout → page |
| `/login` | RootLayout → CommonLayout → page |
| `/admin/dashboard` | RootLayout → **DashboardLayout** → AdminDashboardLayout → page |
| `/doctor/dashboard` | RootLayout → **DashboardLayout** → DoctorDashboardLayout → page |
| `/dashboard/dashboard` | RootLayout → **DashboardLayout** → PatientDashboardLayout → page |
| `/my-profile` | RootLayout → **DashboardLayout** → CommonProtectedLayout → page |

## Verification

1. `npm run dev` চালান
2. `/` visit করুন — "Root Layout" + "Common Layout" দেখাবে (DashboardLayout না)
3. `/admin/dashboard` visit করুন — "Root Layout" + "Dashboard Layout" + "Admin Dashboard Layout" দেখাবে
4. `/doctor/dashboard` visit করুন — "Root Layout" + "Dashboard Layout" + "Doctor Dashboard Layout" দেখাবে
